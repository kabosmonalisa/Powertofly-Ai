Meet with Companies — test guide

Hi Patri — this is a clickable prototype. You can walk through every scenario yourself using the on-screen toggles. Please check that each state shows the right thing and each button lands in the right place.

Open the events page → Go straight to the event page →

1. Where to start

Open the events page and click the Mitsubishi Power "Meet with companies" event — or jump straight to the event page with the button above.

2. How to switch scenarios

On the event page, use the panel at the bottom-right. It has two dials:

EVENT: Upcoming · Live · Reg. closed   |   VIEWER: Logged out · Registered · Not registered

Set a combination, then click the button in the card — it should take you to the correct next screen already in that state.

3. Check each of these

4. On the flow page

There's also a bottom-left AUTH toggle (Logged out / Logged in) and a step jumper (1–5) so you can inspect any screen directly, without filling in the previous steps.

Known — not a bug: the "Join now" / "Join here" buttons don't lead anywhere yet — that live-session/schedule screen isn't built. Everything else should route correctly.

What to flag

Anything where the wrong screen shows, a button dead-ends, or the state doesn't carry through from the event page into the flow. Thanks! 🙏
